## Build pipeline
Parcel 2.16.4 + `@compiled/parcel-config` 0.5.7 with `.compiledcssrc` (`extract: true`, tokens babel plugin first in `transformerBabelPlugins`). Vitest uses `@compiled/vite-plugin` 2.1.0 with the same plugin order.

Findings (verified, see `evidence/`):
1. **Inline import map**: an HTML entry targeting Chrome ≥105 makes Parcel emit `<script type=importmap>`, blocked by WebUI `script-src 'self'`. Fix: `engines.browsers = "Chrome 104"` *transpile floor* on the webui target (not a support claim) → Parcel keeps its chunk manifest inside JS. Audit fails the build if any inline script appears.
2. **Compiled CSS extraction requires an HTML entry** (`@compiled/parcel-optimizer` injects into HTML); a JS-entry build silently drops ADS atomic CSS.
3. **ADS icons use `dangerouslySetInnerHTML`** → blocked by WebUI Trusted Types. Fix: `trusted-types default` + a default policy that accepts only byte-identical glyph strings generated at build time from the imported icon modules (`src/generated/icon-glyphs.ts`); everything else fails closed.
4. ADS pulls `@atlaskit/feature-gate-js-client` → Statsig SDK (remote endpoints as literals; logs "Client must be initialized"). Never initialized; WebUI CSP adds `connect-src 'none'`; runtime test confirms zero egress.
5. `@atlaskit/css-reset` adds `li + li` margins; grid cells reset with tokens.

## Tokens
Only semantic tokens (validated against `@atlaskit/tokens` token-names, 629 names): spacing `space.*`, radius `radius.*`, surfaces `elevation.surface*`, text/icon/border/background semantic colors, `font.body*`/`font.heading*`, motion via ADS components. No raw colors except the user backdrop (validated `#rrggbb`).

## Themes
`setGlobalTheme({light:'light', dark:'dark', colorMode})` with system/light/dark from profile prefs. Verified in Chromium 157: `data-theme`, `data-color-mode`, `--ds-text` = `#292A2E` (light) / `#CECFD2` (dark).

## Typography status
Requested: Atlassian Sans/Mono via ADS typography tokens. Rendered (measured with CDP `CSS.getPlatformFontsForNode`): **Liberation Sans** (Linux CfT fallback). Atlassian app fonts are distributed via Atlassian Mosaic / an "Atlassians only" guide — rights for an independent product unestablished → not fetched, not bundled. Labeled dev fallback; release blocked (licensing-and-assets.md).
